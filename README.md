### ✨ Features

- 🌸 **Delicate Frame & Tabs**: Soft blush window frame, clear active tab contrast, and gentle pastel inactive tabs.
- 🎀 **Aesthetic New Tab Background**: Custom pastel illustration art for your new tab page.
- 🌿 **Eye-Comfortable Omnibox**: Milky white address bar with soft strawberry text contrast.
- ⚡ **Zero Bloatware**: Pure CSS/Chrome theme format, zero performance overhead, zero background memory usage.

---

### 📦 Installation

#### Quick Install (Drag & Drop or Unpacked):
1. Download [`Pinkie-for-Chrome.zip`](Pinkie-for-Chrome.zip) and unzip it into a folder.
2. In Google Chrome (or Edge/Brave), open `chrome://extensions/`.
3. Enable **Developer mode** toggle in the top right.
4. Drag the unzipped folder directly into the `chrome://extensions/` page (or click **Load unpacked** and select the folder).
5. Chrome will automatically apply the Pinkie theme!
